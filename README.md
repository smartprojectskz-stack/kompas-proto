# Светлячок

MVP приложения «Светлячок» — ежедневный эмоциональный чек-ин ребёнка, дашборд родителя
с трендами и рекомендациями, админ-панель модерации и безопасности.

Три роли:
- **Ребёнок** — три возрастных сценария UI (3–6, 7–11, 12–17 лет).
- **Родитель** — дашборд с трендом эмоционального фона, сигналами и рекомендациями.
- **Админ** — обзорная статистика, очередь сигналов риска, список семей, библиотека контента.

## Стек

Next.js (App Router, Server Actions) + TypeScript + Tailwind CSS + SQLite через `@libsql/client`.
По умолчанию база хранится локально в `data/kompas.db` (не коммитится).

## Деплой (Vercel + Turso)

Локальный файл SQLite не переживает бессерверные функции Vercel. Для постоянного
хранения данных подключите бесплатную базу Turso (libSQL) и добавьте в
Environment Variables проекта на Vercel:

- `TURSO_DATABASE_URL` — вида `libsql://...`
- `TURSO_AUTH_TOKEN` — токен доступа к базе

Без этих переменных сайт всё равно работает, но данные не переживают холодный
старт функции — годится только для демонстрации интерфейса.

### Push-уведомления родителю

Чтобы родитель получал push-уведомление на телефон при срабатывании сигнала
безопасности (не заходя в приложение), добавьте в Environment Variables на
Vercel ещё три переменные:

- `VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`
- `NEXT_PUBLIC_VAPID_PUBLIC_KEY` — то же значение, что и `VAPID_PUBLIC_KEY`

Сгенерировать пару ключей можно одной командой:

```bash
npx web-push generate-vapid-keys
```

Без этих переменных приложение работает как обычно — просто push-уведомления
не отправляются, родителю остаётся смотреть сигналы в дашборде.

## PWA

Приложение можно установить на экран телефона как обычное приложение (значок,
отдельное окно) — в браузере это предлагается автоматически либо через пункт
меню «Добавить на экран «Домой»» / «Установить».

## Запуск

```bash
npm install
npm run dev
```

При первом запуске автоматически создаётся учётная запись администратора —
логин и PIN сохраняются в `data/admin-credentials.txt` (в git не попадает) и
выводятся в консоль сервера.

## Важно

Диагностические шкалы, и особенно вопрос-«гейткипер» о безопасности для
подростков 12–17 лет, **должны быть провалидированы лицензированным психологом**
до реального запуска на живых детях. Текущая реализация — MVP/прототип для
демонстрации механики продукта, а не финальный клинический инструмент.

Приложение не ставит диагнозы и не заменяет консультацию психолога или
психиатра.
